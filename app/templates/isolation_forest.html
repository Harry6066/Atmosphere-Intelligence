Algorithm Fundamentals: How Isolation Forest Operates

Liu, Ting & Zhou (2008)
1 Orthogonal Recursive Partitioning

Unlike distance-based or density estimators, an Isolation Forest builds an ensemble of completely random trees. At each node, a random feature is chosen and split uniformly between its minimum and maximum values.

2 Short Path Length Hypothesis

Anomalous observations reside in sparse regions of the 10-dimensional feature space. Consequently, they require significantly fewer splits—i.e., a shorter average path length h(x)—to become isolated in leaf nodes.

3 Decision Score Convention

Scikit-learn maps path lengths to continuous scores via s(x, n) = 2^(-E(h(x))/c(n)). In decision_function(), negative scores indicate anomalies; scores ≥ 0 represent normal observations.

Academic & Meteorological Defense Protocol

1. Statistical Outlier vs Sensor Fault: An unsupervised tree path length measures isolation in standard-scaled multi-feature space. Severe natural mesoscale weather (e.g. blizzards, heat domes, hurricane rainbands) exhibits short isolation path lengths identically to sensor glitches.

2. Contamination is an A Priori Hypothesis: The parameter contamination=0.03 is a calibration threshold, not a measured defect rate. Without ground-truth fault logs, performance cannot be evaluated with precision/recall.
