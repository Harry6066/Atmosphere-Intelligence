4. LOCAL EXECUTION & STARTUP INSTRUCTIONS
--------------------------------------------------------------------------------
To run ATMOSPHERE INTELLIGENCE on your local workstation:

Step 1: Open a terminal inside the project root:
    cd Faulty_Weather_Station_Detection

Step 2: Ensure Python 3.11+ is available and activate your virtual environment:
    # On Windows:
    .\.venv\Scripts\Activate.ps1
    # On Linux/macOS:
    source .venv/bin/activate

Step 3: Install dependencies (if not already installed):
    pip install -r requirements.txt

Step 4: Launch the Flask application:
    python run.py

Step 5: Open your web browser and navigate to:
    http://127.0.0.1:5000

Step 6: Run the automated test suite:
    pytest tests/ -v


5. GUIDED 9-STEP EVALUATION DEMONSTRATION SEQUENCE
--------------------------------------------------------------------------------
When demonstrating or evaluating the ATMOSPHERE INTELLIGENCE platform, follow this
curated sequence to review all 10 modules:

1. Module 1: Project Overview (http://127.0.0.1:5000/)
   - Review high-level platform KPI cards (11,688 total observations, 4 stations, 78 consensus anomalies).
   - Inspect the interactive NOAA station geography map, project objectives, and scientific workflow.

2. Module 2: Dataset Explorer (http://127.0.0.1:5000/dataset-explorer)
   - Filter records by station (Chicago, New York, Seattle, Miami) and anomaly status.
   - Use the live search bar to look up specific dates (e.g., "2019-01-30" or "2021-06-28").
   - Test the live CSV export button to download filtered observation subsets.

3. Module 3: Exploratory Data Analysis (http://127.0.0.1:5000/eda)
   - Inspect empirical probability distributions (histograms and KDEs) across TMAX, TMIN, PRCP, SNOW, SNWD.
   - Analyze Pearson correlation heatmap and climatological annual cycles by station.

4. Module 4: Data Quality & Preprocessing (http://127.0.0.1:5000/data-quality)
   - Inspect NOAA quality flags audit, missing value imputation strategy (forward/backward fill),
     and feature engineering breakdown (TEMP_RANGE, 24h temperature deltas, cyclical day-of-year encoding).

5. Module 5: Isolation Forest (http://127.0.0.1:5000/isolation-forest)
   - Review baseline results (contamination = 0.03, n_estimators = 100, 351 anomalies flagged).
   - Test the interactive parameter sensitivity controls (test contamination = 0.01 and 0.05).
   - Inspect score distribution histograms and tree depth isolation mechanics.

6. Module 6: Local Outlier Factor (http://127.0.0.1:5000/local-outlier-factor)
   - Review baseline density results (k = 20 neighbors, contamination = 0.03, 351 anomalies flagged).
   - Test neighborhood sensitivity (k = 10 and k = 30) and inspect negative outlier factor score curves.

7. Module 7: Model Comparison Engine (http://127.0.0.1:5000/model-comparison)
   - Analyze the Jaccard Paradox: 95.33% binary agreement across all data vs. only 12.50% Jaccard
     similarity on anomaly tails (78 consensus anomalies out of 624 union).
   - Review station-by-station and season-by-season algorithm divergence breakdown.

8. Module 8: PCA 2D & 3D Dimensionality Reduction (http://127.0.0.1:5000/pca-visualization)
   - Explore interactive 2D and 3D scatter plots showing normal points vs. IF, LOF, and Consensus outliers.
   - Inspect the Scree plot (PC1 = 27.96%, PC2 = 16.08%, Cumulative 2D = 44.05%, 3D = 56.25%).
   - Review eigenvector feature loadings explaining the physical drivers of each principal component.

9. Module 9 & 10: Anomaly Investigation & Scientific Insights
   - Navigate to /anomaly-investigation (http://127.0.0.1:5000/anomaly-investigation):
     Review the uncalibrated Severity Index heuristic ranking and deep-dive into individual observations.
   - Navigate to /scientific-insights (http://127.0.0.1:5000/scientific-insights):
     Review the 4 historical extreme weather benchmark audits (2019 Polar Vortex, 2021 Heat Dome,
     2021 Hurricane Ida, 2021 Blizzard) and read the scientific conclusions regarding statistical
     anomalies versus physical sensor hardware failures.
